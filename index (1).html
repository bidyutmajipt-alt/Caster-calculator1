3How the calculation works

Three blocks: the plant cycle (same for all sections), the section calculations, and the metallurgical-length check per grade.

A. Plant cycle

Cast steel per heat = heat size x yield

Liquid steel/yr = annual production / yield

Heats/yr = liquid steel / heat size

Operating min/yr = days x 1440 x availability

Heats possible = operating min / tap-to-tap

Utilisation = heats needed / heats possible (above 100% = target impossible)

B. Casting time allowed

Sequences/yr = heats / heats per sequence

Time per sequence = operating min / sequences

Casting time per heat = (time per sequence - changeover) / heats per sequence

This is the longest a heat may take on the caster while still meeting the annual target.

C. Section geometry

Area = width x thickness (round: pi/4 x d^2)

Weight per metre = area / 10^6 x density

Cut piece weight = kg/m x cutting length

D = smaller side (or diameter), used for solidification.

D. Casting speed

Speed A (tap-to-tap) = cast weight x 1000 / (strands x tap-to-tap x kg/m)

Speed B (annual target) = same formula with the casting time from step B

Design speed = higher of A and B. A keeps up with the converter; B meets the yearly target including changeovers.

E. Metallurgical length

Shell thickness d = K x sqrt(t). Fully solid when d = D/2.

Solidification time t = (D / 2K)^2 min

Metallurgical length = design speed x t

Max speed from length = allowable length / t

F. Verdict

Permissible speed = lower of (max speed from length) and (section max speed x grade factor).

OK when design speed is within permissible speed for every grade and the worst crater end is within the allowable length. Otherwise REVIEW: lower speed, lengthen the machine allowance, review K, add a strand or cut the heat size.

G. Throughput & cutting

Strand t/h = speed x kg/m x 60 / 1000

Pieces/h/strand = speed x 60 / cutting length

Cutting cycle = cutting length / speed x 60 s

Cutting length does not change speed; it drives piece weight and shear/cut-to-length cycle time.

5Run the logic yourself

The same logic is plain JavaScript. Run it in an online compiler, in Node.js, or inside any website.

Method 1 - Online compiler (no installation)
  1. Open the file demo.js in Notepad or any text editor, press Ctrl+A, then Ctrl+C.
  2. Go to an online JavaScript compiler such as onecompiler.com/nodejs, Programiz or JDoodle. Choose JavaScript / Node.js.
  3. Delete the sample code, paste with Ctrl+V, and click Run.
  4. You will see the plant cycle, every section's design speed, metallurgical length and status.
  5. To try your own data, edit the numbers in the EXAMPLE block at the top and click Run again. Percentages are fractions (97% = 0.97).
Method 2 - Node.js on your computer
  1. Install the LTS version from nodejs.org.
  2. Open Command Prompt (Windows) or Terminal (Mac) and go to your folder: cd C:\caster
  3. Check the install: node --version
  4. Run: node demo.js
  5. Edit EXAMPLE in demo.js, save, and run again.
Method 3 - Use the logic inside your own website

Put caster-logic.js beside your page and call calculate():

<script src="caster-logic.js"></script>
<script>
  const result = calculate({
    plant:    { annualProduction:450000, heatSize:60, tapToTap:50, strands:4,
                yield:0.97, operatingDays:330, availability:0.88,
                heatsPerSequence:10, changeoverMin:45, density:7850,
                machineLength:18, allowablePct:0.90 },
    sections: [{ name:'130 Sq', shape:'Square', width:130, thickness:0,
                 cutLength:12, maxSpeed:3.2, share:1 }],
    grades:   [{ name:'Low C', share:1, K:26, speedFactor:1 }]
  });
  console.log(result.sections[0].vDesign);   // design casting speed, m/min
</script>

Output fields: result.plant, result.sections[i] (with gradeRows), result.totals, result.warnings. The page you are on already contains this exact logic inside index.html.

Troubleshooting
  • SyntaxError in compiler: a comma or bracket was deleted. Paste the original again and change one number at a time.
  • calculate is not defined: you pasted caster-logic.js only. Paste demo.js, which includes everything.
  • NaN everywhere: a field is empty or not a number.
  • Warning about shares: section shares and grade shares must each total 100%.

7FAQ

Why is design casting speed the higher of two speeds?
Speed A is what the strands must run so one heat is cast in one tap-to-tap time (the caster keeps up with the converter). Speed B is what the annual target needs after sequence changeovers are subtracted. Running at the higher value satisfies both.
What does REVIEW mean?
At least one check failed: the design speed exceeds the section's max speed, exceeds the permissible speed for a grade, or the crater end falls beyond the allowable metallurgical length. Slightly over the limit (as in the example data) is a prompt to check K values and margins, not necessarily a failure.
What value should I use for K?
K depends on mould and secondary cooling, section size and grade. Values around 20-30 mm/min0.5 are common for billet casters. The example values are placeholders; use your plant's measured or calibrated K for reliable results.
Why does a crack-sensitive grade have a speed factor below 100%?
High-carbon, peritectic and micro-alloyed grades are cast slower to control cracks and segregation. The factor reduces that grade's permitted speed relative to the section maximum.
Does cutting length affect casting speed?
No. It sets cut piece weight, pieces per hour and the cutting-cycle time per piece, which matters for shear or torch cycle capability.
Is my data uploaded anywhere?
No. All calculations run in your browser. Inputs are kept only in your browser's local storage, and "Reset to example" clears them.
How accurate is this?
It is a first-pass design and planning calculator using the standard square-root shell-growth model. Final machine design and operating practice should be validated against plant data, heat transfer modelling and the equipment supplier's limits.
